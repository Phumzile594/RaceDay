# RaceDay Part 1 Completion

## Overview

RaceDay Part 1 establishes the planning and database foundation for the RaceDay event management system.

The completed work covers the system requirements, database design, API planning and project documentation.

## Completed Deliverables

The following Part 1 deliverables have been completed:

- Entity Relationship Diagram (ERD)
- API Endpoint Plan
- SQL Server database script
- Database tables
- Primary and foreign key relationships
- Database constraints
- Realistic sample data
- GitHub Actions CI workflow
- README documentation
- Part 1 presentation video

## Database Implementation

The RaceDay database contains six main tables:

1. Users
2. Profile
3. Events
4. Categories
5. Enrolments
6. Results

The database includes primary keys, foreign keys, unique constraints, check constraints, default values and identity columns.

The SQL script was successfully executed and tested using SQL Server Management Studio.

## Sample Data

The database includes realistic sample data consisting of:

- 2 Organisers
- 2 Participants
- 3 Events
- 6 Event Categories
- 5 Participant Enrolments
- 3 Race Results

## API Planning

The API Endpoint Plan defines 14 REST API endpoints covering:

- Authentication
- User profiles
- Events
- Categories
- Event enrolments
- Race results

The planned endpoints also define the required user roles and expected responses.
